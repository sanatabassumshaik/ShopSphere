# 🛍️ ShopSphere — E-Commerce Product Catalog

ShopSphere is a modern, responsive e-commerce product catalog developed as a full-stack deployment and project architecture capstone.

The project demonstrates modular frontend development, client-side routing, product filtering, product details, shopping cart functionality, browser-based persistence, responsive design, accessibility and performance-conscious development.

## ✨ Features

### 🏠 Home Page

- Modern landing page
- Responsive layout
- Feature highlights
- Clear navigation to products

### 🛍️ Product Catalog

- Product listing
- Product categories
- Product search
- Dynamic filtering
- Product ratings
- Product pricing

### 📦 Product Details

- Individual product pages
- Product description
- Product category
- Product rating
- Product price
- Add-to-cart functionality

### 🛒 Shopping Cart

- Add products to cart
- Remove products
- Update product quantities
- Automatic subtotal calculation
- Total item count
- Persistent cart using Local Storage

### 🧭 Client-Side Routing

ShopSphere uses hash-based client-side routing.
